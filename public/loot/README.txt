Metti qui le icone loot.

Formati supportati:
- .png
- .webp
- .jpg / .jpeg
- .gif

Il sistema prova automaticamente più nomi:
1) id oggetto (es: rusty_iron_dagger.png)
2) nome normalizzato (es: dragon_scale_shield.png)
3) varianti senza suffisso (es: dragon_scale_shield_a -> dragon_scale_shield)

Se un'icona manca, in app resta visibile il fallback grafico.
